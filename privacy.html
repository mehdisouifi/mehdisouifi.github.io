Privacy Policy

Slow Craftworks YouTube Channel Upload Tool · last updated 20 September 2026

This policy covers the private tool used to publish videos to the Slow Craftworks YouTube channel. The tool has a single user: the channel's owner. It is not offered to anyone else and has no sign-up.

What it accesses

With the owner's Google account, and only after the owner approves it in a Google consent screen, the tool uses the YouTube Data API and YouTube Analytics API to:

  • upload videos to the owner's own channel, and set their titles, descriptions, tags, thumbnails and playlists;
  • read the channel's own statistics, such as views and watch time.

It accesses no other Google service, and no data belonging to any other person or channel.

What it stores, and where

An OAuth access token is stored on the owner's own computer, in the owner's user account, readable only by them. Channel statistics are stored in a private repository belonging to the owner. Nothing is stored on a server run by this site, because there is no such server: these pages are static files.

What it does not do

  • No data is sold, shared or transferred to anyone.
  • No advertising, tracking, profiling or analytics of visitors.
  • No cookies are set by these pages.
  • No data is collected from visitors to this site at all.

Deleting the data

Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately invalidates the stored token. Local copies are deleted by deleting them from the computer.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
