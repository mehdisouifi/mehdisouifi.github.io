Privacy Policy

Slow Craftworks TikTok Publishing Tool · last updated 21 October 2026

This policy covers "Jarvis Publisher SC", the private tool used to send videos to the Slow Craftworks TikTok account. The tool has a single user: the owner of that account. It is not offered to anyone else and has no sign-up.

What it accesses

With the owner's TikTok account, and only after the owner approves it on TikTok's own consent screen, the tool uses TikTok's Login Kit and Content Posting API to:

  • read the account's basic profile (its name and avatar), to confirm which account it is connected to;
  • publish the owner's own videos to that account, each one only after the owner has reviewed it and pressed Approve on the tool's "Post to TikTok" page, or send them to the account's TikTok inbox as drafts, which the owner then finishes in the TikTok app

It accesses no data belonging to any other person or account.

What it stores, and where

The access token is stored on the owner's own computer, readable only by the owner. Nothing is stored on a server run by this site, because there is no such server: these pages are static files.

What it does not do

  • No data about visitors, followers or commenters is collected, sold, shared or transferred to anyone.
  • No advertising, tracking, profiling or analytics of visitors.
  • No cookies are set by these pages.

Deleting the data

Because the tool holds no personal data about anyone other than its owner, there is nothing to delete for visitors. The owner can withdraw the tool's access at any time in the TikTok app's settings (Security → Manage app permissions), which invalidates the stored token.
